# Match Lifecycle
- Mulligan: exactly one; select 0–7, return to Deck, shuffle, redraw same count; no penalty/repeat.
- Hand max 10. Draw only to capacity. Undrawn cards remain in Deck in existing order. No burn/discard/exile.
- Compensation: second player's own ACTIVE only; zero-cost single-use Draw1; printed name/ID/flavor OPEN.
- Simultaneous terminal: DRAW.
- Exhaustion: failed draws R1,O2,Y3,G4,B5,V6,W7, then W7 forever. Hit Prime A until INACTIVE, then B, then C. Ordinary Degrade ordering and ordinary post-Degrade DEFENSE apply. Third inactive Prime terminates.
- DEFENSE seconds remain client tuning; Genesis owns legality and timeout-as-PASS only.
