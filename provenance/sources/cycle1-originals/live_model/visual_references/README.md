# Visual references

These images are references, not final production assets.

Current visual direction:
- board chrome should remain quiet/minimal;
- beauty belongs to the generated geometry/manifolds;
- sparse/ghost geometry during construction;
- coherent living manifold after closure/activation;
- Generator cards are manipulated inside expandable Sandbox Domains;
- the field/manifold can form around the cards rather than requiring cards to edge-touch;
- avoid spaceship-control-panel UI styling.
