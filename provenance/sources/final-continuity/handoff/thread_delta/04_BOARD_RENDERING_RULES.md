# Board Rendering Rules

The board should look like a mathematical instrument, not a conventional
wooden card table.

Static/bounded zones: - Deck - Hand - Graveyard - three Prime positions

Dynamic central zone: - Configuration Spaces - unresolved
configurations - resolved Local Manifolds - temporary Sandboxes - QMO
connections - fusion movement/collapse - emergent relationships

The visual system should spend most animation complexity in the dynamic
Configuration Field.

A visual connection must correspond to actual state/QMO relationship.
Rendering cannot imply legality that the math does not contain.

When a configuration closes, the visual reward should be the geometry
cohering into its manifold, not merely a text label saying VALID.

Temporary Sandbox capacity should be visually legible where practical
(e.g. node/structural capacity cues), but exact art direction is not yet
canon.
