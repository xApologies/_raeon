# Chronology, Corrections, and Rationale

The game grew from an existing mathematical/QMO project involving
Chirality Fabric, a 2x2x2 chirality byte, Propagation Engine, closed
manifold/fractal generation, and deterministic visual projection.

The 120 Field Generators are therefore intended to be
mathematical/configurational identities generated by that pipeline, not
120 arbitrary spell cards. The 30 Prime Fields remain a genuine
card-design problem. The 50 Utilities were structurally designed in this
thread.

Base manifold distribution was fixed at 15/13/11/9/7/5 across Red
through Violet. The external recursive landscape was recorded as 343
fusion-derived plus 1,691 emergent objects.

Important correction: a proposed one-per-color Sandbox Utility deck
restriction was explicitly discarded. Final rule is ordinary Utility
identity copy limit 3; Sandbox color controls capacity 3..8.

Important correction: Coupling Stabilizer was rejected because Emergent
Fields are already non-targetable supported relations. Emergent
Amplification replaced it.

Git continuity also changed. Early checkpoint branches caused default
repository access to return obsolete bootstrap state. The repository was
normalized around DESIGN -\> DATA -\> GAME -\> TESTS and promoted to
canonical/default `main`. Future working branches should be temporary
and deleted after merge.
