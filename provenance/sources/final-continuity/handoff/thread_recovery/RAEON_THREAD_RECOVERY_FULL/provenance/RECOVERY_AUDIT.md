# Recovery Audit

This package was built to migrate the originating raeon thread without
relying on chat memory alone.

It intentionally separates: - accepted game rules; -
rationale/corrections; - open design work; - authoritative source
imports still missing; - implementation work that should happen later.

The package does NOT claim to contain the actual external
QMO/Chirality/Propagation/RenderSpec artifacts. Those are explicitly
marked SOURCE_IMPORT_REQUIRED.

The package does NOT claim the 30 Prime catalog is complete. The package
does NOT claim the turn/match state machine is complete. The package
does NOT claim gameplay implementation exists.

A recovered thread must crawl GitHub `main` and reconcile current
committed state before changing design.
