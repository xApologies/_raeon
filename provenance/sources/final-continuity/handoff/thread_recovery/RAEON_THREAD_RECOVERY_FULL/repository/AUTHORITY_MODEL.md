# Repository Authority Model

DESIGN defines accepted game behavior. MATHEMATICS determines
mathematical legality. DATA encodes accepted design/math for
tools/runtime. GAME implements accepted specifications/data. TESTS
verify behavior. DEVELOPMENT tracks maturity/gates/status. PROVENANCE
records history/sources/decisions. CONTENT holds presentation assets.
PLATFORM holds platform-specific integration. PRODUCTION tracks
whole-game lifecycle.

GitHub `main` is canonical committed project state. Chat threads and
handoff ZIPs are working/recovery surfaces.
