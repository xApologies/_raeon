# Game Constitution

1.  Mathematics is the permission system.
2.  QMO is the canonical mathematical object.
3.  Missing data is not TERMINATES.
4.  API states: VALID, TERMINATES, NOT_APPLICABLE, OPEN, UNTESTED.
5.  Closure precedes manifold color.
6.  Rendering cannot redefine mathematics.
7.  Field Generators are geometry/configuration objects.
8.  Three permanent universal Sandboxes form the base configuration
    space.
9.  Committed individual Generators cannot casually move between
    Sandboxes.
10. Emergent Fields are non-targetable supported relations.
11. Black can bend setup/efficiency but not QMO legality.
12. Black Field Generators do not exist.
13. Copy limits are identity-based: FG2, Utility3, Prime unique.
14. Do not silently promote OPEN/WORKING material to GAME_CANON.
15. GitHub `main` is canonical committed project state.
