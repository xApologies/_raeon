# Visual / Rendering Pipeline

Accepted direction: QMO -\> deterministic RenderSpec -\> Blender
procedural geometry -\> mesh asset -\> runtime GPU renderer -\> animated
field/manifold.

Mathematics defines the object. Rendering makes it visible. A
contradictory render is wrong; the QMO is not redefined.

Higher-dimensional QMO state may influence winding, phase, orientation,
deformation, field-shell behavior, emissive flow, animation, and
topology-preserving motion. Blender displays a 3D projection/embedding;
do not claim it literally renders five spatial dimensions.

Board-scale intent: Sandboxes/manifolds appear as coherent active
fields. Selecting a Sandbox enters detailed configuration view showing
committed Field Generators and geometry. Returning to board scale
restores compact field presentation.

Authoritative RenderSpecs, Blender-facing atlas, projection mathematics,
and QMO packages are SOURCE_IMPORT_REQUIRED.

Initial development target: Windows desktop. Secondary intended target:
iPad/iPadOS.
