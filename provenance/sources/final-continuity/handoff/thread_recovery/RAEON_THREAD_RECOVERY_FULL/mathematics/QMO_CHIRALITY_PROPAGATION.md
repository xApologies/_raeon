# QMO / Chirality / Propagation Recovery

## QMO

Queryable Mathematical Objects are first-class mathematical/game
identities. They determine legal closure, fusion, emergence, and
deterministic rendering inputs. The API should explicitly distinguish
VALID, TERMINATES, NOT_APPLICABLE, OPEN, and UNTESTED. Missing data is
not failure.

## Chirality byte / fabric

The thread used a 2x2x2 cube as the smallest orientation structure.
Eight labeled positions can be viewed through six faces; orientation
changes ordering. Four positions are occupied (cradle) and four
unoccupied (void). Occupied positions may carry color. The Chirality
Fabric represents dynamically updating local
energy-density/configuration state.

One discussed face example used A,C,E,G as one face; exact authoritative
labeling/color assignments belong to the external source package and
should not be reconstructed from this summary.

## Propagation Engine

Working project concept: mathematical/fractal seeds are propagated
through Chirality Fabric under closed-domain construction, producing
large QMO structures that can be partitioned into Generator/manifold
objects. Closed shapes/manifolds may include
sphere/circle/triangle/cube/hypercube-like classes or other seed
equations. The authoritative equations and engine are
SOURCE_IMPORT_REQUIRED.

The goal is deterministic math first, then visual realization.
