# QMO Addressing Convention

Recommended canonical addresses:

Base Generator:
`@qmo/raeon/<cycle>/fg-001`

Base manifold:
`@qmo/raeon/<cycle>/manifold/m-r-01`

Fusion-derived manifold:
`@qmo/raeon/<cycle>/derived/fusion/<support-expression-or-hash>`

Emergent field:
`@qmo/raeon/<cycle>/derived/emergent/<support-expression-or-hash>`

Termination record:
`@relation/raeon/<cycle>/termination/<operator>/<pair-or-hash>`

QMO addresses are stable identities.
Do not rename because the artwork changes.
