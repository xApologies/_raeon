# R86 — RELATIONAL MOTION BEYOND DISTANCE

Distance alone cannot encode relational propagation.

There may exist two relational states:

`r_0 != r_1`

with:

`delta(r_0)=delta(r_1)`.

Example class:
one object changes orientation/placement around another at constant separation.

Therefore define the relation state abstractly as richer than its metric projection:

`r = (delta, xi)`

where:
- `delta` is separation;
- `xi` denotes the remaining relational structure resolved by the domain.

No universal coordinate meaning is forced onto `xi`.

## Propagation criterion

Propagation occurs when:

`r_0 != r_1`

under an admissible domain-restricted Bandwidth corridor.

Distance change is only one possible readout of propagation.

## Anchor duality

For two objects `A,B`, choosing `A` or `B` as anchor gives opposite directed readouts of the same relational update.

The invariant event is:

`r_AB^0 -> r_AB^1`.

Statements such as:
- "the ball moved away from the table";
- "the table moved away from the ball"

are anchor-relative readouts when they encode the same change in the ordered relation.

## Transverse component

A transverse distinction is any resolved component of relational change not represented by the current longitudinal/separation readout.

This does not require a fixed absolute transverse axis.

The transverse structure is relation-relative.
