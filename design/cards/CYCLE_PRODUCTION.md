# Reusable Cycle production

Authority: CANON. Future Cycles follow this pipeline unless amended by recorded decision. No stage is complete at bootstrap.

| Stage | Required exit evidence |
| --- | --- |
| SEED | Approved scope, sources, category budgets, OPEN questions |
| GENERATE | Reproducible source-backed candidates and generator/version lineage |
| FORMALIZE | Mathematical admission, explicit effects, schemas, IDs, unresolved outcomes |
| BALANCE | Reviewed playtest/simulation evidence and approved changes |
| RENDER | Source-linked deterministic RenderSpecs and verified presentation assets |
| INTEGRATE | Versioned data/runtime contracts and integrated build |
| TEST | Regression, gameplay, rendering, applicable performance results |
| RELEASE | Accepted source/artifact revisions, manifest, provenance, checkpoint, approval |

Use design/cards/cycle_NN/ for design, data/cycles/cycle_NN/ for data/manifests, and content/ for assets. Record stage status, evidence, reviewer, and revision. NOT_APPLICABLE requires reviewed rationale; missing mathematics never silently passes.
