# System design boundaries

The [accepted rules](../game/ACCEPTED_RULES.md), [Utility structure](../cards/cycle_01/UTILITIES.md) and [accepted state](../../data/manifests/accepted-state.json) are the existing system authority. This index connects those records without defining competing card catalogs.

- Sandbox: three permanent universal Domains; temporary colored capacity 3–8, exempt permanent base, normal Utility identity copy limits. Capacity is not closure.
- Activation: READY → USED on ordinary use, eventual refresh to READY, early USED → READY for eligible already-earned objects; exact timing OPEN.
- Transduction: Restore/Degrade/Universal charge ladders; no Utility overrides QMO legality.
- Recovery: Graveyard resources return to circulation; no automatic topology reconstruction or ordinary Prime resurrection.
- Protection: protects existing legal structures; no invented closure or Prime identity changes.
- Emergent Fields: no independent attack/destruction; required support loss removes access. Amplification +1 capped at Violet preserves all support restrictions. Coupling Stabilizer was rejected because direct-field protection conflicts with or redundantly complicates this model.

See [rendering architecture](RENDERING.md) and [board interaction](../ui-ux/README.md) for presentation direction. Mathematics and APIs remain SOURCE_IMPORT_REQUIRED.
