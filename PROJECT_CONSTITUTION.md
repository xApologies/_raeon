# raeon. project constitution

Authority: CANON — governance; game rules are GAME_CANON only where explicitly accepted. This is a standalone project. Do not access, copy, import, reference, or derive content from other repositories or another game's constitution. Do not invent unrelated systems.

## Canonical state

GitHub (https://github.com/xApologies/_raeon), branch main, is the single canonical accepted project tree. The Git repository is canonical storage; temporary working branches are proposals until validated and accepted into main, then deleted. Chats, Codex sessions, and _inbox are workspaces/transfer media, never canonical storage. No automatic merge to main is authorized.

## Game authority

THE MATHEMATICS IS THE PERMISSION SYSTEM. The QMO is the canonical mathematical game object. Use [accepted rules](design/game/ACCEPTED_RULES.md) and source records; never reconstruct authoritative mathematics from prose/counts. Preserve SOURCE_IMPORT_REQUIRED and OPEN until reviewed evidence changes them.

## Production

Whole-game state: PREPRODUCTION. Substantial external mathematical/system prototypes await import. Architecture alone does not advance the game to Prototype. Follow the twelve [production phases](production/README.md); none is complete at bootstrap. Windows desktop first; iPad/iPadOS secondary.

## Authority labels

| Label | Meaning |
| --- | --- |
| CANON | Accepted raeon project state |
| GAME_CANON | Accepted raeon-specific game/math rule |
| SOURCE_IMPORT_REQUIRED | Accepted artifact exists but is not yet imported |
| PROVISIONAL | Working state |
| OPEN | Unresolved |
| UNTESTED | Not validated |
| TERMINATES | Explicit mathematical failure |
| NOT_APPLICABLE | Gate/query does not apply |

VALID is also a mathematical API outcome, not an authority label. Never silently promote OPEN to CANON or equate missing data with TERMINATES. Gate/module/lifecycle status is separate from authority.

## Amendments

Record decisions with scope, source, rationale, affected invariants, validation, explicit acceptance, and supersession links. Update structured data and dependent docs together. Conflicting imports remain quarantined until authority is resolved. Compiled binaries require later explicit policy before commit.
